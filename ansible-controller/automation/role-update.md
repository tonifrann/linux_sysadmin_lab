# Rol: update

Este rol aplica las actualizaciones del sistema operativo en todos los servidores que gestiona por Ansible.


## 1. Funciones del rol

El rol realiza:

- Actualización de la lista de paquetes

- Instalación de las actualizaciones 

- Aplicación de parches de seguridad

- Reinicio opcional si el sistema lo requiere 


## 2. Tareas del rol

El rol mantiene los sistemas al día y aplicar los parches de seguridad.
